# AI Prompts Collection

A comprehensive collection of AI prompts organized by application and use case.

## Quick Start

- View all prompts and their applications in [`prompt_applications.md`](./prompt_applications.md)
- Each prompt file includes metadata about which AI application it's designed for

## Structure

```
AI_Prompts/
├── prompt_applications.md    # Master registry of all prompts
├── README.md                 # This file
└── [individual prompt files]
```

## Browse by Application

See [`prompt_applications.md`](./prompt_applications.md) for the complete list of prompts organized by AI application.
